# StageCue 接口说明

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。

所有业务入口在/api下；会话Cookie鉴权，写请求使用auth/csrf返回的header和token。不要记录、公开或在浏览器持久存储这些凭据。正常JSON返回实体或详情，业务错误返回HTTP状态和code。

## 身份与管理

GET auth/csrf；POST auth/login（username、password）；GET auth/me；POST auth/logout；POST auth/password（oldPassword、newPassword）。登录有应用内限速；账号停用、改密码和降权即时核验。密码至少12位且含大小写数字，BCrypt输入最多72字节。

GET／POST admin/{type}；PUT／DELETE admin/{type}/{id}。type为users、roles、departments、menus、permissions、dictionaries、settings。管理要求admin及ALL，采用有限字段输入；用户不接受passwordHash。内建权限、菜单及参数不创建或删除；总部不能删除；引用由外键保护。权限目录仅改名称，类型已有编码不能改，参数限timezone／companyName／maxRecords，maxRecords为100～1000。

## 查询

GET options 返回有限表单目录，不返回密码或无权业务。业务GET {type}（productions／books／runs），参数search（最多120）、status、page（0～10000）、size（1～100）、sort（newest／oldest）。返回content和total，total为授权结果数量。制作目录不按状态筛选。

GET {type}/{id} 返回record和events；books另含cues和editors；runs另含executions和holds。纯执行岗位只返回本人提示及其执行证据。GET {type}/{id}/report.json以attachment返回同范围详情，另要求export。

GET dashboard要求dashboard，按可见场次计算runs、states、cueTotal、cueDone、held；GET audit要求audit并按部门／本人过滤。

## 草稿与目录写入

POST {type}，PUT {type}/{id}，type为productions／books／cues／runs。所有输入要求requestKey为标准小写UUID；编辑另要求version为详情当前整数版本。

| 类型 | 允许字段 |
| --- | --- |
| productions | reference、name、departmentId、enabled |
| books | productionId、title；新建自动使用下一个版次并复制最近批准版 |
| cues | bookId、sequence、code、kind、triggerText、description、optional、enabled |
| runs | reference、bookId、callerId、supervisorId、location、plannedAt、mode |

reference／code最长60，name／title最长120，location最长200，triggerText最长300，description最长1000。sequence为1～9999，kind为LIGHT／SOUND／STAGE／VIDEO，mode为REHEARSAL／PERFORMANCE。plannedAt使用含明确UTC或偏移的ISO8601时刻，接受1970-01-01T00:00:01Z至2038-01-19T03:14:07.999999Z，超出为400 INVALID_TIME，纳秒输入统一截断为微秒。状态、审批摘要、执行事实和操作人由服务器决定。

制作编号与部门、提示本制作、提示所属版、场次编号与来源版不允许编辑。只有草稿／退回版可改提示；场次编辑限岗位准备状态且符合写入范围。业务没有DELETE接口。

## 命令

POST {type}/{id}/commands/{action}，body为requestKey、version、note，指派命令另有operatorId。note必填，最多1000；version指被操作实体（提示本／场次／执行／暂停）的版本，执行操作引起场次版本同步变化。

| type | action | 权限／职责 |
| --- | --- | --- |
| books | submit、withdraw、cancel | book.write；撤回／作废限创建人 |
| books | approve、reject | book.review；不得参与当前版编辑 |
| executions | assign | run.write、写入范围；仅岗位准备；指定启用cue.operate账号 |
| executions | receive、ready、done | cue.operate，且为本条指派账号 |
| executions | standby、call、skip | run.call，且为本场提示员 |
| runs | start、resume、end、abort、cancel | run.call，且为本场提示员 |
| runs | hold | run.hold，且为本场提示员或已指派操作员 |
| runs | close | run.review，且为本场指定独立监督员 |
| holds | resolve | run.review，且为本场指定监督员及不同提出人 |

所有实际时间由服务端UTC微秒记录，不接受客户端实际时间。执行是人工台账动作，不调用设备协议。状态及闭合条件见操作手册。

## 重试与错误

UUID指纹绑定操作人、路径动作、目标和完整载荷。授权仍有效时，同内容精确重试返回原成功响应；载荷变化重用键为REQUEST_KEY_REUSED。失败事务回滚，没有消费请求键。前端内容变化自动产生新键。

| 状态 | 典型code |
| --- | --- |
| 400 | INVALID_INPUT、INVALID_REQUEST_KEY、INVALID_ACTION、WEAK_PASSWORD |
| 401 | UNAUTHENTICATED、LOGIN_FAILED |
| 403 | FORBIDDEN、OUT_OF_SCOPE、ASSIGNED_CALLER_REQUIRED、ASSIGNED_OPERATOR_REQUIRED、ASSIGNED_SUPERVISOR_REQUIRED |
| 404 | NOT_FOUND |
| 409 | STALE_VERSION、INVALID_STATE、INDEPENDENT_REVIEW_REQUIRED、CREW_NOT_READY、CUE_OUT_OF_ORDER、MANDATORY_CUE_CANNOT_SKIP、OPEN_HOLD、UNFINISHED_CUES、EXECUTION_STILL_OPEN、OPEN_REVISION、SUPERSEDED_BOOK、CONFLICT |
| 429 | LOGIN_THROTTLED |

未经书面授权不得商用。接口响应、客户数据、证据导出和运行日志不附加广告。
