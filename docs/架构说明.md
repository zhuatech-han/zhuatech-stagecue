# StageCue 架构与数据

## 组件

Vue3提供同一套桌面与窄屏业务、岗位和管理页面。Nginx同源代理/api及健康入口，Spring Boot负责会话、权限、事务和状态规则，MySQL保存全部业务。数据库只接受容器网络连接。前端开发代理配置与生产Nginx分开。

Java21、Spring Boot4.0.7、Security、JPA、Flyway、MySQL8.4；Node24.19、Vue3.5.40、Vite8.1.5。版本详见README和锁文件。自有代码适用非商业源码LICENSE，第三方各自许可适用。

## 数据

V1__identity.sql创建9张身份表：department、access_role、permission、role_permission、nav_menu、account、audit_event、system_setting、dictionary_entry。

V2__stage_cues.sql创建9张业务表：

| 表 | 事实与约束 |
| --- | --- |
| production | 唯一制作编号、负责部门、创建人、启停、版本 |
| cue_book | 制作＋版次唯一、名称、状态、创建／批准人与时刻、内容摘要、版本 |
| book_editor | 当前版所有参与编辑的账号，版次＋账号唯一 |
| cue_definition | 本版顺序和提示编号分别唯一、类型、标记、说明、可选／列入、版本 |
| show_run | 唯一场次编号、来源版次及摘要、独立快照名称、部门／创建人、指派岗位、性质、计划、状态、结果、事实时刻、版本 |
| cue_execution | 本场顺序唯一、来源提示、全部文本快照、指定操作员、收悉、待命／就绪／提示／完成记录和版本 |
| run_hold | 暂停提出人、原因、时刻、独立处理人与说明、状态和版本 |
| command_record | 唯一UUID、操作人＋完整请求指纹、成功响应JSON |
| business_event | 类型／对象、操作人、动作、说明、追加快照和时刻 |

共18张自有表，另有Flyway历史表。必要外键保护部门、账号、制作、版次和来源提示；初始版本为1，SQL约束阻止不合法序号与版本。无物理业务删除接口；提示本草稿通过“列入此版”管理提示是否有效。目录启停保留已有业务。

## 冻结与变更

一个制作最多一个未闭合草稿版。下一版复制最近批准版有效提示，版次逐次增加，不覆盖旧版。当前版本所有编辑人员均记入book_editor，不能审批本版。批准后状态、文本、摘要、审批事实不能编辑。

场次创建只接受当时最新批准版，复制有效提示、名称、版次和摘要。之后新版本获批也不会换写已有场次；需要改版时取消未开始的原场次，再从新版创建。已经开始的场次不支持换版、换岗或实际时间更正。

每条提示指派操作员，操作员收悉本场冻结版本。重新指派清除本条收悉；编辑准备中场次清除全部收悉。所有收悉和账号启用／岗位权限验证通过才允许指定提示员开始。

## 执行与暂停

只处理最先未完成提示。必执行提示须完成；可选提示只能在尚未提示时说明略过。提示员通知待命、指定操作员就绪、提示员记录提示发出、本人回报完成。时间是服务端记录时刻，不是实际设备遥测。

暂停阻止新的待命、就绪、提示发出与略过。已提示任务允许在暂停中回报完成。指定监督员处理开放暂停，提示员恢复，所有未提示的待命／就绪回到待执行；每次重置追加证据，旧证据保留。

全部提示闭合后结束并由指定监督员复盘。中止可保留未执行提示，但不能遗留已提示未回报任务或开放暂停；中止和完成结果不会在复盘后混同。

## 权限

接口权限和数据范围分开核验。ALL／DEPARTMENT／SELF作用于制作与关联版次；场次还允许明确指派的提示员、监督员和操作员读取。只有run.write且符合创建范围的账号可编辑场次、指派操作员。

纯执行岗位只看本人提示和关联场次，即使ALL也不扩大提示或场次发现范围。场次概况、暂停和场次级证据可读，本人之外的提示快照和执行证据过滤。管理员也必须满足具体指派，不能凭admin执行他人的提示或代替指定监督员复盘。

每次操作重新从数据库核验账号启用、密码散列、角色权限。只返回安全账号字段，密码和散列不进入页面、导出或业务证据。导出复用详情的权限与范围。

## 事务与容量

所有写入采用READ_COMMITTED事务和总部固定行锁，和后台管理写入共用锁；拿锁后刷新账号与角色。版本防止旧页面覆盖，UUID指纹绑定账号、动作、对象与完整字段。精确重试返回原成功响应，改变载荷重用键拒绝；失败事务不保留键、状态或事件。

主业务类型各最多1000，可设100～1000；每版200条提示；目录最多10000；页面最多100条。有限列表在授权过滤后排序和分页，统计仅聚合授权记录。单组织串行写属于明确容量边界，没有大型并发、多实例或实时控制验收声明。

软件证据是业务数据库记录，内容摘要识别版次；不属于可信电子签名、设备执行证明或防篡改外部账本。
