# StageCue 操作手册

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2。

## 初始化与岗位

按部署说明启动，以admin和私有配置中的初始化密码登录。空库没有演出记录。先建立实际部门和账号，分别分配制作协调、独立监督、提示员与技术操作员。提示员、监督员及操作员不能在同一场互相兼任。

账号页可停用和重置密码，角色页设置15项接口权限与数据范围。权限目录、菜单和参数是内建资源，只允许修改有限名称及配置；最后一位启用管理员不能被删除、停用或降权。点击自己的账号可修改本人密码，修改后重新登录。

## 制作和提示本

1. 制作协调建立制作编号、名称及负责部门，停用后不能建立新版或场次。
2. 在制作详情“建立提示本版次”，或提示本列表“新建”选择制作。每个制作只能有一个未完成草稿。
3. 添加提示，填写顺序号、编号、灯光／声音／舞台／视频类型、台词或动作标记、执行说明。序号和编号在本版唯一。
4. 至少一条必执行提示；其他可标为允许略过。“列入此版”关闭时不复制到场次。
5. 提交审批。未参与本版任何编辑的独立监督账号批准或退回。退回可编辑；创建人可撤回提交或取消未批准版。
6. 批准后文本冻结。需要修订时新建下一版，自动复制最近批准版有效提示，修改后独立审批。旧版保留。

## 编排场次

制作协调选择当前最新批准版，填写场次编号、场地、上海时区计划时刻、排练／正式场次，指定提示员和不同的监督员。系统复制该版所有有效提示，并保存名称、版次及摘要。

在每条提示上指派启用且有执行权限的操作员。操作员用自己的账号查看被指派场次，逐条“确认收悉此版”。重新指派清除对应收悉，编辑准备中场次清除全部收悉，需重新确认。

全部提示指派和收悉后，由指定提示员“记录场次开始”。计划时间不自动启动场次，系统按钮只登记人工核实操作，不向设备发信号。

## 提示执行

由第一条未完成提示开始：提示员记录待命通知，指定操作员确认就绪，提示员记录提示发出，操作员回报执行完成。各动作填写核实说明或凭据编号。

前序尚未完成不能跳到后序。必执行提示不能略过；可选提示可在尚未提示时说明略过。已提示不能取消或略过，应核实完成事实后回报。多个提示不并行推进。

页面按需刷新查看其他岗位已登记的动作；一期无实时推送。界面中的时刻是软件登记时间，现场发令、对讲和实际设备操作须使用专业设施与适用程序。

## 暂停与恢复

运行中，本场提示员或被指派操作员可提出暂停。暂停后禁止新待命、就绪、提示记录和略过；已记录提示的任务可以回报完成。

指定监督员核实处理并填写说明。所有开放暂停处理完后，提示员记录恢复。尚未发出的待命／就绪回到待执行，须重新通知和确认；之前的通知证据保留。

暂停记录本身不代表设备急停或任何现场安全功能。软件暂停仅阻止本台账的相应状态推进。

## 结束、中止和复盘

全部提示完成或合法略过后，提示员结束并提交复盘。无法完成整场时，可记录中止；中止前处理暂停并回报所有已提示任务。未执行提示保留原状态，结果保留“中止”。

指定监督员查看提示、暂停、操作人、时间和说明，完成独立复盘。已结束、中止或复盘的场次不能继续提示。准备中可由提示员取消场次；已有场次快照不自动换版，开始后也不换岗。

## 查询和导出

列表搜索制作名、提示本名、编号或场地，提示本与场次可按状态筛选，按新增顺序排序和分页。统计只包含当前权限范围真实记录。

业务详情“下载业务证据”导出JSON，权限与页面一致，纯执行岗位仅含本人提示及可见场次证据，不包含其他提示内容、密码或推广文案。对未发布演出内容按组织制度保管。

出现“记录已变化”时，关闭表单、刷新并核对新状态后重新操作；精确内容重试可保留请求键，改变说明或版本的请求会使用新键。
